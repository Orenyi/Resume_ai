# Resume AI 🚀

Resume AI is an AI-powered resume builder designed to help job seekers create professional, ATS-friendly resumes quickly and efficiently.

The platform combines modern resume templates, AI-assisted resume generation, PDF export, multi-language support, and cloud-based resume management into a single user-friendly experience.

## 🌐 Live Demo

https://resume-aim-two.vercel.app/

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/your-username/resume-ai.git
```

### Navigate Into Project

```bash
cd resume-ai
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
